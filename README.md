# AI备忘录 Android

这是与 Windows 桌面端完全分离的原生 Android 客户端，项目目录为
`D:\VS\AI-Memo-Android`。当前版本已形成从 AI 识别、人工校正到本地提醒的
完整闭环，并加入本地收支记录与统计；日程和账目默认只保存在手机本地。

## 当前功能

- 智谱 GLM 文本和视觉理解，支持单个视觉理解模型或文本/视觉理解分开配置
- 使用系统照片选择器并兼容 HEIC、PNG、WebP、JPG 和相册云端图片
- 单次最多选择 4 张图片，逐张识别并合并成功结果
- 默认文本模型 GLM-4.7-Flash，默认视觉理解模型 GLM-4.6V-Flash
- 409、429 等临时错误自动重试，空识别结果自动生成可编辑待办
- 图片首次未提取到日程时自动细致复查，并恢复被截断响应中的完整条目
- 识别结果保存前可逐条编辑和删除
- 未配置 AI 时提供“手动添加”与“前往填写 Key”两种快捷入口
- 使用免费默认模型时说明能力限制，连接超时后可直接进入模型配置页
- 手动添加、编辑、完成和删除日程
- 删除、确认完成和恢复待办均需二次确认，支持多选后批量确认完成或删除
- 日程概览按今天、明天、后天、未来、未设日期和已过期分段展示
- 剩余时间按天、小时和分钟组合显示，并每分钟刷新
- 提醒通知同时显示距离日程开始还有多久
- 日期、开始/结束时间、地点、备注、紧急程度和重复安排
- 点击日程卡片可滚动查看完整标题、备注和其他详情
- 只有日期没有时间时，按当天中午 12:00 计算
- 未设置日期的待办，在每次打开应用时提醒一次
- 第一次、第二次和最后一次三阶段系统提醒
- 高优先级声音、振动和顶部横幅通知，内置通知测试入口
- 通用通知、精确提醒和电池优化设置入口，适配不同 Android 系统
- 手机重启、系统时间或时区改变后重新安排提醒
- 提醒历史可查看和删除
- 日程可导出为本地备份并再次导入，导入时自动跳过重复内容
- 收入、支出流水记录，金额按分精确保存
- 每笔流水可设置分类、备注以及具体发生日期和时间
- 流水按月份浏览，支持编辑和删除
- 月总结显示收入、支出、结余以及分类占比
- 年总结显示全年收支、结余、12 个月明细和年度分类汇总
- 夜间主题和按天、时、分配置提醒
- Android 13 及以上的通知权限申请
- 禁止 Android 云备份日程数据库和设置

## 技术结构

- Kotlin 2.1
- Jetpack Compose + Material 3
- SQLiteOpenHelper 本地数据库
- AlarmManager + BroadcastReceiver 系统提醒
- StateFlow + AndroidViewModel 状态管理
- 智谱 OpenAI 兼容 HTTP 接口
- 最低 Android 8.0（API 26），目标 Android 15（API 35）

## 构建

需要 JDK 17 和 Android SDK 35。首次构建会通过 Gradle Wrapper 下载依赖。

```powershell
powershell -ExecutionPolicy Bypass -File .\build_apk.ps1
```

构建产物：

```text
release\AI-Memo-Android-v0.5.0.apk
```

当前 APK 已启用 R8 代码与资源压缩，并使用开发签名以便覆盖安装测试版本。
正式公开分发前仍应改用受保护且长期保存的发布签名。

API Key 只保存在应用私有设置中，不写入源码。AI 识别时仅发送用户本次选择
的文字或图片；日程和记账数据库不会上传。
