# AI备忘录 Android

这是与 Windows 桌面端完全分离的原生 Android 客户端，项目目录为
`D:\VS\AI-Memo-Android`。当前版本已形成从 AI 识别、人工校正到本地提醒的
完整闭环，并加入本地收支记录与统计；日程和账目默认只保存在手机本地。

## 当前功能

- 支持智谱 GLM 与 DeepSeek 文本和视觉理解，支持单个视觉理解模型或文本/视觉理解分开配置
- 使用系统照片选择器并兼容 HEIC、PNG、WebP、JPG 和相册云端图片
- 单次最多选择 4 张图片，逐张识别并合并成功结果
- 日程和记账图片识别均可直接调用相机拍照
- 智谱默认文本模型 GLM-4.7-Flash、视觉理解模型 GLM-4.6V-Flash；DeepSeek 默认文本模型 deepseek-v4-flash、视觉理解模型 deepseek-v4-flash-vision-exp
- 409、429 等临时错误自动重试，空识别结果自动生成可编辑待办
- 图片首次未提取到日程时自动细致复查，并恢复被截断响应中的完整条目
- 识别结果保存前可逐条编辑和删除
- 未配置 AI 时提供“手动添加”与“前往填写 Key”两种快捷入口
- 使用免费默认模型时说明能力限制，连接超时后可直接进入模型配置页
- 手动添加、编辑、完成和删除日程
- 删除、确认完成和恢复待办均需二次确认，支持多选后批量确认完成或删除
- 日程概览按今天、明天、后天、未来、未设日期和已过期分段展示
- 剩余时间按天、小时和分钟组合显示，并每分钟刷新
- 提醒通知同时显示距离日程开始还有多久
- 日期、开始/结束时间、地点、备注、紧急程度和重复安排
- 点击日程卡片可滚动查看完整标题、备注和其他详情
- 只有日期没有时间时，按当天中午 12:00 计算
- 未设置日期的待办，在每次打开应用时提醒一次
- 第一次、第二次和最后一次三阶段系统提醒
- 高优先级声音、振动和顶部横幅通知，内置通知测试入口
- 通用通知、精确提醒和电池优化设置入口，适配不同 Android 系统
- 手机重启、系统时间或时区改变后重新安排提醒
- 提醒历史可查看和删除
- 底部导航精简为日程、记账和设置，智能添加与提醒记录并入日程页
- 日程页可按需显示已完成日程和已提醒日程
- 新提醒使用持久化未读标记，右上角通知入口与底部日程导航同步显示红点或未读数量
- 日程操作栏使用紧凑下拉菜单，统一收纳新建方式、备份操作和日程筛选
- 备份由 Android Keystore 自动管理密钥并使用 AES-GCM 加密，无需用户设置或记忆密码
- 自动加密备份包含日程、账单和预算设置，恢复时自动跳过重复内容
- 收入、支出流水记录，金额按分精确保存
- 每笔流水可设置分类、备注以及具体发生日期和时间
- 记一笔分类以图标网格完整展开，覆盖常见收支场景，并支持持久保存自定义分类
- 自定义分类可在分类卡片上直接删除，已有账单历史保留
- 支持一次描述多条收入和支出，由大模型拆分账目并分别判断收支类型、金额、分类和备注
- 记账支持一次选择最多 4 张购物清单、超市小票或账单图片，逐项识别金额并匹配分类
- 图片首次未提取到有效账目时自动放大复查，并避免把商品明细与合计重复记账
- 多条账目全部完整时事务写入并提示检查；任一字段不确定时整批转为逐条编辑后统一保存
- 流水按月份浏览，支持编辑和删除
- 流水支持多选、全选和批量确认删除
- 月总结显示收入、支出、结余以及分类占比
- 年总结显示全年收支、结余、12 个月明细和年度分类汇总
- 月总结和年总结可直接设置当前周期预算，每个具体月份、年份分别保存不同额度
- 预算按实际支出显示进度、剩余额度或超支金额
- 月总结和年总结增加收支折线图，分别按天和按月展示支出、收入、结余
- 月度和年度总结增加支出、收入分类饼图，展示金额最高的前十类及占比
- 月总结和年总结支持用户主动调用 AI 分析收入、支出分类与结余，并生成消费建议
- AI 消费建议采用流式输出；用户未点击分析时不会发送账单汇总
- API Key 使用 Android Keystore 与 AES-GCM 加密保存，设置页不再回显完整 Key
- 禁止明文 HTTP 请求，并阻止携带 Key 的请求自动跟随重定向
- 日程、账单、提醒历史、自定义分类和预算设置使用 Android Keystore 密钥加密保存
- 进入后台时取消 AI 网络请求并清空内存中的敏感状态
- 禁止截图、录屏、最近任务预览和 Android 12 以上的悬浮层覆盖
- 设置页可关闭截图与录屏保护；关闭需先确认隐私风险并设置或验证安全密码，重新开启无需密码
- 锁屏通知使用私密可见性，降低日程内容从锁屏泄露的风险
- 日间、柔和、夜间三种主题，首次打开默认使用柔和模式
- 按天、时、分配置提醒
- Android 13 及以上的通知权限申请
- 禁止 Android 云备份日程数据库和设置

## 技术结构

- Kotlin 2.1
- Jetpack Compose + Material 3
- SQLiteOpenHelper 本地数据库
- AlarmManager + BroadcastReceiver 系统提醒
- StateFlow + AndroidViewModel 状态管理
- 智谱与 DeepSeek OpenAI 兼容 HTTP 接口
- 最低 Android 8.0（API 26），目标 Android 15（API 35）

## 构建

需要 JDK 17 和 Android SDK 35。首次构建会通过 Gradle Wrapper 下载依赖。

```powershell
powershell -ExecutionPolicy Bypass -File .\build_apk.ps1
```

构建产物：

```text
release\AI-Memo-Android-v0.9.7.apk
```

当前 APK 已启用 R8 代码与资源压缩，并使用开发签名以便覆盖安装测试版本。
正式公开分发前仍应改用受保护且长期保存的发布签名。

API Key、日程、账单、提醒历史、自定义分类和预算设置使用 Android Keystore 密钥加密后保存在应用私有目录中，不写入源码。自动加密备份绑定本机应用密钥，不包含可导出的明文密钥。AI 识别时仅发送用户本次选择
的文字或图片到当前选择的 AI 服务；用户主动点击消费分析时，仅发送当前月份或年份的分类汇总、
收支总额与结余。逐笔流水、日程和本地数据库不会上传。
